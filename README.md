# EGC

Proiecte pentru laboratoarele obligatorii 02 si 03, realizate cu C# / .NET 8, OpenTK 4.9.4 si OpenGL 3.3 Core. Fiecare branch contine un singur laborator, pregatit separat pentru descarcare.

- [lab02](https://github.com/AlexPintilie08/EGC/tree/lab02) — triunghi rgb, fundal animat, input, rasterizare, miscare si deformare CPU; include raspunsurile Word.
- [lab03](https://github.com/AlexPintilie08/EGC/tree/lab03) — forme indexate, culori HSV, unda in vertex shader si pauza; include raspunsurile Word.

In branch-ul laboratorului, deschideti fisierul `.csproj` in Visual Studio 2022 sau rulati `dotnet restore`, `dotnet build -c Release` si `dotnet run` in folderul proiectului.
